**"Lottery Symbol",2017, DApp.**

A graphical symbol on the blockchain, chosen via a simple lottery (using the blockchain itself as a source of entropy).

This is a piece in a series of works that pair methods of allocation with aesthetic properties. It follows on from [Democratic Palette](/2016/07/11/democratic-palette/).

You can access it via an Ethereum-enabled browser [here](https://show.rhea.art/artworld-ethereum/dapps/lottery-symbol/build/index.html) and the source code is available in a git repository [here](https://github.com/rheaplex/artworld-ethereum/tree/master/dapps/lottery-symbol).
